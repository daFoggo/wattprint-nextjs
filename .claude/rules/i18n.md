# i18n: rules an agent must not miss

Source of truth: docs/internationalization.md. ESLint catches JSX text, text attributes, hardcoded locales and `next/link`; `tsc` catches a key missing from `en`.

- Text outside JSX (toast messages, labels in config objects, `generateMetadata`) also comes from `messages/{vi,en}/<namespace>.json`.
- Vietnamese is the default (no prefix); English under `/en`. Currency reads `2.380 ₫`.
- `i18n/routing.ts` stays identical in both apps (verify compares them).
- `notFound`/`forbidden` stay from `next/navigation`; everything else from `@/i18n/navigation`.
