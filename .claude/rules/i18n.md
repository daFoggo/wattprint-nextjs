# Text and languages: rules agents miss

Source of truth: `docs/internationalization.md`. ESLint already forces navigation through `@/i18n/navigation`.

- No hardcoded user-visible text: add it to `messages/{vi,en}/<namespace>.json` (Vietnamese first, English complete), then `useTranslations` / `getTranslations`.
- Numbers, currency and dates format with the current locale (`useLocale()` / `getLocale()`), never `"en-US"` or the browser default. Vietnamese currency reads `2.380 ₫`.
- A new visible string inside a Hairline component needs a patch plus an entry in `packages/ui/src/lib/hairline-messages.ts`.
