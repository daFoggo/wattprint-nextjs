# CI build without a backend (lane M, bug fix)

Record: GitHub CI red since "fix(dashboard): eval-free Ajv stub…" (user 2026-11-24: "linting test ci cd build rồi push").
Base: web 029ba02.

## Failures (CI logs, reproduced on a clean clone with API_BASE_URL=http://localhost:1/api/v1)
1. typecheck: `PageProps` not found on a clean checkout — the route type helpers are generated by next dev/build/typegen
   into `.next/types`. Fix: `typecheck` runs `next typegen && tsc --noEmit`.
2. build: `/en/dashboard/settings` prerender fetched the cached provinces (`getProvinces`, "use cache") in a
   Promise.all beside the session read. Fix: read the session first; provinces only after it (prerender stops at the
   session, so no fetch at build).
3. build: `/en/sign-in` prerender ran the cached demo homes fetch; a failed fetch inside a cache scope fails the
   prerender even though `getDemoHomes` catches it. Fix: `await io()` before the cache call (rule: io over
   connection), so it runs at request time; still cached for the hour; outage still means no demo button.

## Proof
Clean clone: `pnpm turbo run lint typecheck test` 17/17; `pnpm build` with a dead API exits 0 (failed before with 2, then 3).
Auth tests: the mock of next/cache gains `io`.

## Areas of concern
- Sign-in no longer bakes the demo list into the static shell: the button streams in per request (from the cache).
- Settings: provinces fetched after the session, not in parallel (cached for days, so near zero).
